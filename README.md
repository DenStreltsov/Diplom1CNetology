#ИНСТРУКЦИЯ ПО НАЧАЛЬНОЙ НАСТРОЙКЕ

Все вновь добавленные объекты (справочники, документы, регистры, константы) доступны в подсистеме «Добавленные объекты». После обновления конфигурации выполните следующие шаги.

##Шаг 1
В справочнике Дополнительные реквизиты у предопределенных элементов справочника установить Тип реквизита в соответствии со следующей таблицей:
|Наименование элемента справочника	|Тип реквизита	|
|Дата начала действия договора		|Дата		|
|Дата окончания действия договора	|Дата		|
|Ежемесячная абонентская плата		|Суммовой	|
|Стоимость часа работы специалиста	|Суммовой	|

##Шаг 2
Создайте группу и бота (с правами администратора) в Телеграм. Зафиксируйте токен бота. 

##Шаг 3
Получите идентификатор группы:
1.	Напишите любое сообщение в группу
2.	С помощью браузера или программы Postman выполните запрос https://api.telegram.org/bot[ВашТокен из шага 1]/getUpdates. В полученном JSON найдите идентификатор группы (chat_id), в которой получено сообщение. Зафиксируйте идентификатор.

##Шаг 4
Добавьте менеджеров и специалистов по обслуживанию в ранее созданную группу телеграм с ботом.

##Шаг 5
Создайте в справочнике Номенклатуру с названием «Абонентская плата» или другим аналогичным по смыслу. 
Создайте в справочнике Номенклатуру с названием «Обслуживание по заявкам» или другим аналогичным по смыслу. 

##Шаг 6
Заполните следующие константы: 
«Номенклатура абонентская плата» — заполняется из справочника Номенклатура элементом, созданным в шаге 5; 
«Номенклатура работы специалиста» — заполняется из справочника Номенклатура элементом, созданным в шаге 5;
«Токен ТГ Бот» — заполняется токеном бота телеграмм, созданным в шаге 2;
«Идентификатор группы ТГ» — заполняется идентификатором группы телеграмм, зафиксированном на шаге 3;
«НДФЛ» - заполняется величиной соответствующего налога на расчетный период.

##Шаг 7
В «Общих настройках» установите истина у «Свойства». Добавьте дополнительный реквизит в группе «Пользователи» с наименованием «Категория». Тип значения «Перечисление.КатегорияСотрудников». В поле «Для Разработчиков» укажите: «КатегорияСпециалиста».

##Шаг 8
В справочнике пользователи заполните у сотрудников дополнительный реквизит «Категория» соответствующим значением. (У административного персонала при начислении зарплаты учитывается оклад, а у специалистов дополнительно к окладу еще процент от выполненных работ).

##Шаг 9
Заполните регистр сведений «Условия оплаты сотрудников», укажите процент от работ у Специалистов и оклады у всех сотрудников. Для удобства процент отражается только у специалистов.

##Шаг 10
В справочник «Графики работы» заведите необходимый вид графика работы. В поставке есть уже предопределенные «пятидневный» и «шестидневный». Затем в подсистеме «Добавленные объекты» в разделе «Сервис» выберите обработку «Заполнение графика». В поле «Выбор периода» выберите период (год) для заполнения графика. В поле «Выходные дни» через запятую перечислите порядковый номер выходного дня недели. Например: 6,7 (как суббота и воскресенье). В поле «График работы» выберите вид графика согласно справочнику «Графики работы» (например, предустановленные «пятидневный» или ранее созданный). Нажмите кнопку «Заполнить». Далее в регистре «Графики работы» проверьте корректность заполнения графика. Каждому рабочему дню должно соответствовать значение «1».

##Шаг 11
В справочнике «Пользователи» для каждого сотрудника на вкладке «Права доступа» назначьте соответствующий должности профиль группы доступа. Дополнительно к имеющимся предустановлены следующие профиля групп доступа без возможности их изменения: 
«Бухгалтер ИТ Фирмы» - для бухгалтеров;
«Кадровик расчётчик» - для кадровика;
«Менеджер» - для сотрудников, обрабатывающих заявки на абонентское обслуживание
«Специалист» - для сотрудников, занимающихся Абонентским обслуживанием.
С составом ролей вышеназванных профилей групп доступа можно ознакомиться: «Администрирование» → «Настройки пользователей и прав» → «Профили групп доступа» — папка «Дополнительные профили».

##Шаг 12
Ознакомить пользователей с новыми возможностями программы и дополнительными требованиями по заполнению данными:
Для бухгалтера:
- возможность автоматического формирования документов реализации товаров и услуг по Абонентским договорам за месяц с помощью обработки «Массовое создание актов» (Добавленные объекты → Сервис). Период в обработке — это дата отчетного месяца, которая также будет установлена как дата реализации. 
- для случая ручного создания документа реализации товаров и услуг на форму добавлена кнопка «Заполнить», по нажатию которой в табличную часть «услуги» при заполненной в договоре контрагента абонентской плате добавляется строка с Номенклатурой из константы «Номенклатура абонентская плата» с соответствующими данными по величине абонентской платы, а также строка с Номенклатурой из константы «Номенклатура работы специалиста» с указанием количества отработанных часов по всем заявкам за месяц даты документа, стоимости одного часа работы специалиста из договора контрагента и сумма по выполненным работам. Этот же механизм используется при массовом создании реализаций;
- при формировании документа «Выплата зарплаты» автоматическое заполнение начислений за расчетный период;
- дополнительный контроль за расходованием отпусков при проведении документа начисления зарплаты с видом расчета Отпуск:
- новый отчет «Анализ выставленных актов» для контроля выставления реализаций по договорам абонентского обслуживания. 
Для менеджера:
- возможность создавать договор контрагента вида «Абонентское обслуживание». Для них реализованы дополнительные поля: «Дата начала действия договора» и «Дата окончания действия договора», «Ежемесячная абонентская плата», «Стоимость часа работы специалиста». Эти поля должны быть заполнены для корректного формирования документов обслуживание клиента и реализации товаров и услуг. В частности дата Документа обслуживание клиента должна быть в диапазоне вышеназванных дат. в противном случае программа выдаст ошибку. А отсутствие абонентской платы напротив ошибки не выдаст, но в реализации будет отсутствовать соответствующая строка.
- автоматическая отправка уведомлений в группу телеграм о создании новых или изменениях в существующих (плановые даты работ или специалист) документа обслуживание клиента (после проведения документа);
- наличие планировщика «Календарь специалистов» на стартовой странице с указанием загрузки специалистов по созданным документам Обслуживание клиентов
- возможность создавать новый документ обслуживание клиента прямо из планировщика с автозаполнением Специалиста, плановых дат и времени (в пределах одного рабочего дня).
Для кадровика-расчетчика:
- необходимо для каждого существующего и вновь принимаемого сотрудника указывать значение дополнительного реквизита «категория» в справочнике пользователи;
- об алгоритмах расчета зарплаты (для специалистов с учетом процента от работ), а также о возможности начисления разовой премии с использованием документа «Начисление фиксированной премии»;
- о возможности планирования отпусков с помощью документа «График отпусков» с визуальным отображением периодов отпусков при нажатии кнопки «Анализ графика», позволяющим отследить пересечения отпусков специалистов.
- новый отчет «Выработка специалистов»;
- новый отчет «Расчеты с сотрудниками»;
- новый отчет «Расход запланированных отпусков»;
Для специалистов:
- при заполнении документа Обслуживание клиента возможность прикреплять файл, например, о проделанных работах за подписью клиента;
- отчет «Выработка специалистов».
